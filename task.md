Polza Agency
Тестовое задание на позицию
Вайбкодер-аутричер

Контекст. Мы - аутрич-агентство. Генерируем B2B-лиды для клиентов через email-рассылки. Тебе предстоит собирать базы, писать цепочки и автоматизировать рутину с помощью AI-инструментов. Это задание показывает, как ты думаешь и работаешь руками.


Продукт для аутрича

Ты продвигаешь Polza Agency - агентство по запуску email-аутрича для B2B-компаний. Целевой клиент: компания с продуктом (или услугой) для бизнеса, которая хочет получать входящие заявки через холодные рассылки.

Задания
Задача 1: Сбор базы
Собери базу потенциальных клиентов для Polza Agency.
Минимум 50 компаний - B2B, Россия, есть отдел продаж или активно ищут клиентов.
Для каждой компании: название, сайт, имя и email. (могут быть и другие данные дополнительно)
Инструмент сборки - любой (Apollo, LinkedIn, парсеры карт, Claude Code-скрипт и т.д.).
Результат: Google Таблица с заполненными столбцами.
Инструмент
Apollo / LinkedIn / Claude Code / 2ГИС / Яндекс / любой 
Задача 2: Персонализация
Добавь персонализацию к каждому контакту в базе.
Для каждой строки: короткий персональный факт о компании или ЛПР (1–2 предложения).
Источник: сайт, LinkedIn, новости - не выдумывать.
Реализовать через скрипт на Claude Code или Cursor: на входе - список компаний, на выходе - столбец «Персонализация» в таблице.
Приложи сам скрипт (ссылка на репозиторий или файл).
Инструмент
Claude Code / Cursor / Codex / Kimi code
Задача 3: Цепочка писем
Напиши цепочку из 3 писем от имени Polza Agency.
Письмо 1 - холодное знакомство с крючком под ЦА.
Письмо 2 - фолоу-ап через 3 дня, другой угол / кейс.
Письмо 3 - финальный фолоу-ап через 5 дней, мягкий выход.
Каждое письмо: тема + тело. Длина - до 120 слов.
В письме 1 использовать переменную {{персонализация}} из задачи 2.
Оформить в отдельном документе или в той же таблице отдельным листом.
Инструмент
Claude Code / Cursor / Codex / Kimi code любой AI



Задача 4: Персонализация нашей базы
Ниже будет ссылка на таблицу, в которой ты найдешь 15 компаний для такой же персонализации, как в задаче 2. Только теперь будь начеку, вдруг мы что-то перепутали…

База для тестового задания

Приложи ссылку на таблицу или документ в формате XLSX/CSV.


Инструмент
Claude Code / Cursor / Codex / Kimi code любой AI


Задача 5: Вайбкод/LLM-инженер стек
Напиши свой опыт в работе с LLM. Чем больше своих мыслей по каждому пункту, тем лучшею.


Твой выбор IDE и LLM моделей сейчас и как он менялся последние полгода.
Сколько и каких подписок в месяц тебе хватает для полноценной работы.
Как сравниваешь две новые модели или инструмента - по ощущениям или на одинаковом наборе задач? 
Какие тесты ты потребуешь для новой функции? 
Какие разрешения ты дашь coding-агенту, имеющему доступ к терминалу и базе? 
Пишешь ли ты автоматические тесты и включаешь ли их в CI/CD? Какие проверки должны обязательно пройти перед слиянием и деплоем
